# Contributing

This repository is maintained by its owner. Open an issue before changing commercial terms, privacy wording, product capabilities or historical content. Use a short-lived branch and a pull request; do not force-push the default branch.

Install with the frozen lockfile, make the smallest coherent change, then run typecheck, lint and build. Test the affected routes and keyboard/mobile behaviour. Keep secrets and runtime artifacts out of commits. Do not submit real enquiries as a test.
